- 현재 등수별 선수 명단에서 호명하는 선수를 한 등수씩 올려주는 문제

## [유연근무제](https://school.programmers.co.kr/learn/courses/30/lessons/388351)

### 💡 아이디어 / 접근법

- 출근 인정 시각이 각 직원별로 주어지고 그 직원이 이번 주 개근했는지 체크하는 문제
